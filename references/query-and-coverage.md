# 地址、余额与仓位覆盖

用于只读查询、数据源选择、协议发现和 RPC 故障排查。资金执行另读 execution.md。

## 地址导入

- 支持用户实际提供的格式，例如一行一个地址、`1: 地址`、`1：地址`，清理 BOM、首尾空白及空行。不要从任意混合文本中宽松截取地址而忽略同一行的秘密字段。
- EVM 先用相应链工具校验 20 字节地址及适用的混合大小写校验和，再生成大小写无关的去重键；保留显示地址。仅做长度正则检查不能宣称完成校验和验证。
- Solana 用 Base58 解码或 PublicKey 工具校验 32 字节公钥，不能只看字符数量，也不能转小写去重。有效公钥可能是程序账户或 PDA；转账签名能力要另外验证。
- 导入整批失败时给出行号及原因分类，不回显无效原文，因为错误行可能是私钥或助记词。
- 地址有效不等于在每条链有资产。不同链的身份与查询结果分别记录。

## 不混淆余额查询与资产发现

| 需求 | 可行路径 | 不能据此推出的结论 |
| --- | --- | --- |
| EVM 原生币 | `eth_getBalance` | 不包含 ERC-20、LP 或借贷仓位 |
| 已知 ERC-20 | 对指定合约执行 `eth_call balanceOf` 并核对精度 | 常用币种清单不等于全部持仓 |
| 发现未知代币 | 已获授权的索引服务，或限定范围的事件扫描后核对余额 | 转账事件不保证当前仍有余额，rebasing 等资产也不能简单只按事件记账 |
| Solana 代币 | 分别查询经典 SPL Token 与 Token-2022 程序的 `getTokenAccountsByOwner` | 非零代币账户不等于可直接转账；NFT、扩展代币及 LP 需另识别 |
| LP/质押仓位 | 针对协议版本读取仓位、池子和相应质押合约 | 钱包没持有 LP NFT 不等于不存在已质押仓位 |

没有覆盖完整历史或协议清单时，把发现结果标为有限覆盖。不要为了“全资产”盲扫每条链从创世区块到最新区块；先评估查询数量、节点限制及用户的完整性要求。

## RPC 与精度

1. 先核实 EVM chainId 或 Solana 完整 genesis hash；不要把网络昵称当作唯一校验。
2. 小批量验证后再批量运行。JSON-RPC 批量结果按 id 关联，不能依靠返回数组顺序；缺项按失败处理。
3. 只读请求对超时、429 和部分 5xx 可有限重试并退避；凭证错误、付费额度不足、无效方法或明确不支持不能无限重试。
4. 固定区块读可提高单链一致性，但公共端点可能限制历史状态。若任务只需当前余额且端点拒绝历史查询，可改用 `latest` 并记录逐项时间及一致性降级；历史核账任务不能悄悄降级为当前余额。
5. 余额和金额运算使用 BigInt/任意精度；格式化才应用 decimals。ERC-20 `eth_call` 返回 `0x` 是空返回，不是零余额。Solana 金额优先使用整数字符串；JSON 数值先检查是否超过安全整数范围。
6. 保留最近成功结果时，应另标“历史值”和新请求失败，不能把旧值当新值，也不能用失败覆盖成零。

## LP 最小核查

以 Uniswap V3 直接持有仓位为例：核对该链官方部署的 Position Manager，读取持仓数量、tokenId、positions、币对、流动性、fee tier 和区间。只读成功与可撤出分别判断。

- 不假定所有链的合约地址相同。
- 分页或数量上限触发时标记部分覆盖。
- 元数据读取失败不能吞掉整个仓位而报空仓位。
- `tokensOwed` 可能不含尚未结算的全部手续费，不能直接标作完整可领取金额。
- 存入质押合约、vault 或 NFT 托管合约的仓位需要单独适配所有权关系；其他 V2/V3/V4 实现不能按名称硬套同一 ABI。
- Solana SPL 代币余额扫描本身不提供完整 Raydium/Orca 等 LP 识别。

## 本项目遇到的故障：作为诊断线索，不固化为平台事实

| 观察（2026-09-23） | 有效处理 | 避免的误判 |
| --- | --- | --- |
| DeBank 返回 403，脱敏分类含 insufficient/units | 停止批量请求，核对所属项目额度；用户选择免费 RPC 后不再依赖 DeBank | 不能认为所有 403 都是额度不足，也不能据此规避接口授权 |
| Arbitrum 某公共节点拒绝固定旧区块，明确要求归档凭证 | 当前余额任务改读 latest，并标明不保证整个扫描同一区块 | 不是 Arbitrum 链本身不能读取历史 |
| Node 在受限环境立即返回 EACCES | 识别本机运行权限问题，按环境许可运行同一授权查询 | 不要把全部钱包标为无资产或泄露代理配置来排查 |
| 一个 Solana 公共端点超时，另一个可达 | 验证备用端点的完整网络标识后再接入 | 不要以截短的 genesis hash 校验主网 |
| 某浏览器工具本机权限失败 | 对本地开发页面使用可用的 Playwright/浏览器验证方式 | 不说明 DeBank 网页本身不可用 |
